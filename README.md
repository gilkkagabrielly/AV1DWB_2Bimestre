# Projeto AV1 - DWB

Aplicação web que consome a API Rick and Morty.

## Tecnologias
- HTML
- CSS
- Bootstrap
- JavaScript

## Funcionalidades
- Listagem de personagens
- Consumo de API com fetch
- Loading e tratamento de erro

## Parte 2 - Funcionalidades

- Página de listagem de personagens
- Página de detalhes individual
- Navegação entre páginas via URL
- Consumo de API com parâmetros dinâmicos
- Uso de Fetch API com async/await
- Tratamento de erros e loading
